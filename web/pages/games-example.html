Play Android games on PC with open-emulator

A step-by-step look at running Android games on a Windows, Linux, or macOS desktop — with a real, isolated virtual machine per account instead of one shared profile.

  1. Download and run the wizard. First launch walks through a host check, the Android SDK license, and creating your first machine.
  2. Install the game's APK from the Install panel, or sign into the Play Store inside the guest like a normal device.
  3. Map mouse and keyboard to on-screen taps from the Keymap panel — click the guest screen to place a binding, then fire it from the keyboard.
  4. Clone a second machine from the tab bar to run a second account of the same game alongside the first, fully isolated.
