An Android emulator that runs in mint, not in a browser tab.

open-emulator is a native desktop shell around real, isolated Android virtual machines — clone as many as you need, switch between them with a top tab bar, and control every one from a single mint sidebar. No ads. No account.

Why open-emulator

Every machine is really its own machine.

Each tab is a separate Android Virtual Device with its own userdata disk, sdcard, and console/adb ports — not a shared profile switch. Clone one to fork its state, or delete it without touching the rest.

Isolated instances

Create, clone, start, stop, and delete Android VMs independently. Run five accounts of the same game side by side.

Tab multiplexer

A top bar switches the active machine LDPlayer-style, without opening a new window for every instance.

Keymap editor

Click the guest screen to place bindings, then fire them from the keyboard — built for games that expect a mouse and keys.

Mint install wizard

Host checks, an explicit Android SDK license step, guest download, and first-machine setup — one guided flow, no manual SDK wrangling.

Real control plane

open-emu is a real CLI underneath the GUI: install APKs, push/pull files, spoof GPS, tune performance — scriptable, not just clickable.

Open source core

Apache-2.0 licensed. The Android SDK itself is fetched from Google under its own license at setup time — never bundled, never redistributed.

Early access

No ads, no telemetry, no account walls today. That's a deliberate starting point — see the roadmap for what a sustainable version of this looks like.
