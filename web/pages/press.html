open-emulator, in brief

A mint-branded, open-source Android emulator built around isolated, multi-instance virtual machines and a native desktop shell — an LDPlayer-class emulator without the closed-source core.

Boilerplate (feel free to quote)

"open-emulator is an open-source, mint-branded Android emulator for desktop. Each virtual machine is fully isolated — its own disk, storage, and network ports — and a top tab bar switches between them like browser tabs, LDPlayer-style. The Android SDK itself is fetched from Google at install time under Google's own license and is never bundled."
