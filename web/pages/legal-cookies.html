Cookie policy

Last updated 2026-08-13

This site does not set tracking cookies of its own. It uses exactly one piece of browser storage, plus (only if you accept the consent banner and a real ad account is configured — see below) a third-party ad network's own cookies.

NameTypePurpose
oe_consentlocalStorage (not a cookie)Remembers whether you accepted or declined the consent banner, so it doesn't ask again. See web/public/consent.js.
AdSense cookiesThird-party cookieOnly set if web/public/ad-config.json has a real publisher id configured and you accepted the banner. As shipped, that config is empty, so nothing loads. See web/public/ads.js.

Declining

Choosing "Decline" on the banner stores that choice the same way (in oe_consent) and prevents the ad slot from ever loading a third-party script, for as long as that storage persists.

The desktop app is unrelated

None of this applies to the desktop application, which has its own, separate consent step in the install wizard — see Privacy.
