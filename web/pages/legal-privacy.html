Privacy

Last updated 2026-08-13

Short version: neither this website nor the desktop app collects analytics, telemetry, or advertising data today. This page will be updated, with a new date above, if that ever changes — see the monetization plan for what a future ad-supported build would add and how it would be disclosed here first.

This website

No analytics script, no third-party tracking pixels, and no cookies. Pages are static files served as-is.

The desktop app

The app does not run any analytics, crash reporting, or advertising SDK, and does not phone home to any server this project operates. Network activity a user can trigger:

ActionDestinationWhy
Install wizard's "Download SDK" stepGoogle's Android SDK serversFetches the Android SDK/Emulator/system image, only after the license step is explicitly accepted.
The emulated Android guest's own network accessWhatever the guest OS/apps reachIt's a real virtual machine — apps installed inside it behave as they would on a physical device.
Update check (sidebar footer)A static JSON feed, only if configuredOff by default until a real release feed exists. Plain HTTP GET, no identifiers attached.

Keymaps, macros, the instance list, GPS spoofing values, performance settings, and the SDK license-acceptance flag are stored only on the local machine and never transmitted anywhere.
